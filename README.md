# দৃষ্টিভ্রম / Illusion Lab

বাংলা ভাষার এক-ফাইলের optical illusion gallery। `index.html`-এ সব HTML, CSS ও JavaScript আছে; কোনো external asset, library, cookie বা tracker নেই।

## প্রদর্শনী

- ঘূর্ণায়মান বর্গ—motion pause ও intensity control
- হারম্যান গ্রিড
- অসম্ভব ত্রিভুজ
- নিরাপত্তা নির্দেশনাসহ ১৫-সেকেন্ডের afterimage পরীক্ষা
- দুই প্রশ্নের ছোট কুইজ

Keyboard focus, semantic labels, live status এবং `prefers-reduced-motion` সমর্থন রাখা হয়েছে।

## GitHub Pages

Branch publishing বেছে নিলে GitHub repository Settings → Pages-এ `main` branch এবং `/ (root)` source নির্বাচন করতে হবে। GitHub Pages-এর plan ও repository-visibility নিয়মের জন্য [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) দেখুন। GitHub-এর নথি অনুযায়ী GitHub Free-তে Pages public repositories-এর জন্য উপলভ্য; eligible plan-এ private source repository থেকেও public site প্রকাশ করা যায়। Pages website নিজে ইন্টারনেটে public হতে পারে।
